# Guide pour suivre les sorties d anime par saison

Les sorties d anime sont souvent organisees autour des saisons de l annee. Pour les suivre clairement, separez trois informations : date de debut, statut de diffusion et format.

## A verifier avant de commencer

- Verifiez si la serie est en cours, terminee ou encore annoncee.
- Distinguez TV, film, OVA, ONA et special ; tous ne suivent pas un rythme hebdomadaire.
- Verifiez la plateforme officielle disponible dans votre region.
- Utilisez la note comme reference, pas comme garantie de gout personnel.

AniVideos importe les metadonnees AniList et les stocke localement afin de ne pas interroger l API a chaque visite. La disponibilite est presentee via des liens officiels, jamais via des copies hebergees par AniVideos.
