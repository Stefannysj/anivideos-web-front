# Guía para seguir estrenos de anime por temporada

El anime suele organizar muchos de sus estrenos alrededor de temporadas del año. Para seguirlos de forma ordenada conviene separar tres datos: fecha de inicio, estado de emisión y formato.

## Qué revisar antes de empezar

- Comprueba si la serie está en emisión, finalizada o todavía anunciada.
- Distingue TV, película, OVA, ONA y especial; no todos siguen una programación semanal.
- Verifica la plataforma oficial disponible en tu región.
- Usa la puntuación como una referencia, no como una garantía de afinidad personal.

AniVideos importa metadatos de AniList y los almacena localmente para evitar consultar la API en cada visita. La disponibilidad de reproducción se consulta mediante enlaces oficiales, no mediante copias alojadas por AniVideos.
